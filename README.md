# SCT_ML_4

# 👍 Hand Gesture Recognition using CNN

## 📌 Project Overview
This project focuses on recognizing hand gestures using Deep Learning and Computer Vision techniques. A Convolutional Neural Network (CNN) model was trained on image data to classify multiple hand gestures with high accuracy.

## 🚀 Features
- Hand Gesture Classification
- CNN-based Deep Learning Model
- High Training & Validation Accuracy
- Accuracy and Loss Visualization
- Real-time Prediction Ready

## 🧠 Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## 📂 Dataset
LeapGestRecog Dataset from Kaggle:

🔗 https://www.kaggle.com/datasets/gti-upm/leapgestrecog
